# Cloud Computing Concepts Reflection

Cloud computing has become a part of my everyday life, even before I learned about it in class. Many of the applications I use rely on cloud technology to store data, provide online access, and make communication easier.

Three cloud services I use regularly are Google Drive, Facebook Messenger, and Canva. These are examples of Software as a Service (SaaS) because they allow users to access their features through the internet without installing complex software. They also use the Public Cloud since they are available to anyone with an internet connection. Google Drive helps me store and share files, Messenger allows me to communicate with family and friends, and Canva makes it easy to create presentations, posters, and other school projects.

Git and GitHub are important because they provide version control, which helps developers keep track of changes made to a project. They also make teamwork easier by allowing members to work on the same files, review updates, and restore previous versions if needed.

Overall, this activity helped me understand that cloud computing is already part of my daily routine. It also showed me how Git and GitHub support collaboration and make managing cloud-based projects more organized and reliable.
